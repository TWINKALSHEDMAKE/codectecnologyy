\# Intrusion Detection System (IDS) using Machine Learning



\## Objective

To detect malicious network traffic using machine learning techniques.



\## Dataset

KDD Cup 99 (10% subset)



\## Tools \& Technologies

\- Python

\- Pandas

\- Scikit-learn



\## Machine Learning Algorithm

\- Random Forest Classifier



\## Steps

1\. Load and preprocess network traffic data

2\. Convert categorical features to numeric

3\. Train Random Forest model

4\. Evaluate model accuracy



\## Result

The model successfully classifies normal and attack traffic.
